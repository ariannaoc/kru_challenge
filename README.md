# Kru Challenge — Normalización de Datos
### Herramienta *client-side* para estandarización y validación de archivos `.csv` de RRHH y nómina hacia el modelo de datos de Kru

**Autora:** Arianna Olivares  
**Stack:** React + Vite

---

## Requisitos previos

* **Node.js** `v20.19+` o `v22+`
* **npm** `v10+`

---

## Instalación y ejecución local

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. Abrir en el navegador la URL indicada en consola y arrastrar o seleccionar los archivos `.csv` del cliente
